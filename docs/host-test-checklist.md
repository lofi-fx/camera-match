# Resolve 21.1 host test checklist

Use a disposable project and copy of test media. Quit Resolve after saving, run `./build-and-launch.sh` to build, install in `/Library/OFX/Plugins/`, and relaunch. Confirm **Camera Match** appears in OpenFX under LoFi FX and renders an unchanged frame before capture. Record Resolve log messages if it does not load.

1. **Overlay:** On the Color page, select the effect node and activate **Open FX Overlay** in the viewer tool menu. Verify TL/TR/BR/BL handles draw and drag. Repeat at Fit, 25%, 50%, 100%, 200%, pan, Retina display, and viewer resize. Test the center translation handle, patch toggle on click but not drag, sample move/resize, Escape, lost focus, node switch, and two instances.
2. **Geometry:** Test a strongly skewed chart, an invalid crossed corner, portrait and UHD footage, half/quarter proxies, non-square PAR, and a chart partly outside the frame. Compare selected sample IDs with the physical target. Check that inspector edits and undo/redo update the overlay.
3. **Hero and target:** Capture hero on camera A. Add a fresh Camera Match node to camera B, select the same chart model, align, and press **Apply Hero to This Clip**. Verify it reports the hero name and Reference status keeps the hero fingerprint and revision. Refit after changing exclusions. Confirm edits to sample geometry require recapture. Also copy the original hero node to camera C and press Apply Hero; C must use its embedded hero. Restart Resolve, press **Use This Hero for Other Clips** on the saved hero node, then apply it on another fresh node.
4. **Persistence:** Save/reopen and copy a solved node to a clip without a chart. Verify the correction renders without viewer or chart frame. Test undo/redo for drag, capture, and solve. Render a short export with overlay shown and hidden; pixels should match.
5. **Controls:** With Exposure 0%, compare linear DWG luminance before and after on positive patches and held-out footage. Check Bypass and all-zero controls for identity. Verify a +1-stop synthetic exposure chart gives approximately 2× at 100% and √2 at 50%.
6. **Real footage:** Use at least two camera models and two lighting setups, including roughly ±1 stop exposure differences. Compare chart residuals and held-out skin/objects. Watch repeated frames for pumping or artifacts. Record rejected patches separately from in-sample error.

If DrawSuite is not advertised or the overlay fails to receive events, diagnose the actual host suite/event path before treating this build as accepted. If hidden OFX strings truncate, migrate snapshots to fixed versioned numeric parameters; do not rely on process memory for render data.
