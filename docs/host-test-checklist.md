# Resolve 21.1 host test checklist

Use a disposable project and copy of test media. Quit Resolve after saving, run `./build-and-launch.sh` to build, install in `/Library/OFX/Plugins/`, and relaunch. Confirm **Camera Match** appears in OpenFX under LoFi FX and renders an unchanged frame before capture. Record Resolve log messages if it does not load.

1. **Overlay:** On the Color page, select the effect node and activate **Open FX Overlay** in the viewer tool menu. Verify TL/TR/BR/BL handles draw and drag. Repeat at Fit, 25%, 50%, 100%, 200%, pan, Retina display, and viewer resize. Test the center translation handle, patch toggle on click but not drag, sample move/resize, Escape, lost focus, node switch, and two instances.
2. **Geometry:** Test a strongly skewed chart, an invalid crossed corner, portrait and UHD footage, half/quarter proxies, non-square PAR, and a chart partly outside the frame. Compare selected sample IDs with the physical target. Check that inspector edits and undo/redo update the overlay.
3. **Reference and target:** Capture `Scene 1` and `Scene 2` on separate reference nodes. On fresh camera B nodes enter the corresponding name in **Apply reference named**, align, and press **Apply reference to this clip**. Verify Scene 1 never receives Scene 2's fingerprint. Check an unknown name fails without changing the saved correction. Refit after changing exclusions. Confirm edits to sample geometry require recapture. Copy a reference node to camera C and press Apply reference with the name field empty; C must use its embedded reference. Restart Resolve, press **Use this reference for other clips** on both saved reference nodes, then apply each by name on fresh nodes.
4. **Overlay after capture:** With Open FX Overlay selected and **Show color chart overlay** enabled, capture a reference and apply it on a target. Verify the corner and patch lines remain visible and draggable. Toggle Show color chart overlay off and on; the guide should disappear and return. After restarting Resolve, reselect Open FX Overlay in the viewer to show the guides.
5. **Persistence:** Save/reopen and copy a solved node to a clip without a chart. Verify the correction renders without viewer or chart frame. Test undo/redo for drag, capture, and solve. Render a short export with overlay shown and hidden; pixels should match.
6. **Controls:** With Exposure 0%, compare linear DWG luminance before and after on positive patches and held-out footage. Check Bypass and all-zero controls for identity. Verify a +1-stop synthetic exposure chart gives approximately 2× at 100% and √2 at 50%.
   **Inspector layout:** Verify Capture, Apply reference adjustments, Color chart, and Reference adjustments are collapsible and in that order. Verify Bypass, Reference status, and Status appear above the collapsed Advanced section. Reopen a saved node and confirm its values remain intact.
   **Match method:** Apply the same reference with Existing match and RBF match on separate target nodes. Verify Hue, Saturation, Exposure, and Neutral controls appear only for Existing match; RBF weight appears only for RBF match. Check RBF strength at 0/50/100/200%, including neutral patches. Save/reopen both nodes and confirm the applied method and output persist. Switch methods on a solved node and confirm the correction updates immediately. Check playback and export performance at UHD with Metal enabled.
7. **Real footage:** Use at least two camera models and two lighting setups, including roughly ±1 stop exposure differences. Compare chart residuals and held-out skin/objects. Watch repeated frames for pumping or artifacts. Record rejected patches separately from in-sample error.

If DrawSuite is not advertised or the overlay fails to receive events, diagnose the actual host suite/event path before treating this build as accepted. If hidden OFX strings truncate, migrate snapshots to fixed versioned numeric parameters; do not rely on process memory for render data.
